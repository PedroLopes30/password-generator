# Gerador de Senhas Seguras 🔐

## Sobre o Projeto
Este projeto é um Gerador de Senhas Seguras desenvolvido como Trabalho Prático para a disciplina de Programação para Internet (PPI) - 1º Bimestre - 2026.


## Funcionalidades
* Definição do tamanho da senha (variando de 6 a 32 caracteres).
* Inclusão opcional de letras maiúsculas, minúsculas, números e caracteres especiais.
* Indicador visual de força da senha (Fraca, Média, Forte, Muito Forte) utilizando uma barra colorida.
* Botão integrado para copiar a senha gerada diretamente para a área de transferência.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página.
* **JavaScript :** Lógica de sorteio, validações e manipulação do DOM.
* **Tailwind CSS:** Estilização do front-end.
